# Repository guidelines

- Always communicate with users in Simplified Chinese.
- Public documentation must be available in both English and Simplified Chinese.
- Keep setup procedures short and focused on zero-code instrumentation.
- Document only capabilities backed by a released Beacon language project.
- Do not mention unrelated observability products in documentation, source comments, metadata, or examples.
- When a language supports profiling, keep its profiling setup next to the language quick start.
- Run `npm run check` and `npm run build` before considering documentation changes complete.
